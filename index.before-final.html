DocCollab‑v0

Crie documentos técnicos com rigor sem lidar com LaTeX.

Criar Documento

Proposta de valor

Editor baseado em blocos semânticos que produz um AST JSON validado — a única fonte de verdade — e gera PDF automaticamente.

Problema

Ferramentas como Overleaf expõem LaTeX ao autor, causando atrito e erros em documentos técnicos complexos.

Método DocCollab

Fluxo determinístico e auditável:

  1. Blocos semânticos no editor
  2. AST JSON rigorosamente validado
  3. Conversor AST → LaTeX (automático)
  4. Compilação em engine LaTeX isolada → PDF

Tipos de documento

  • Artigo científico
  • Relatório técnico
  • Dissertação / TCC
  • Manual de engenharia
